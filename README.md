# AI-Civic-Issue-Reporter

An AI-powered web application that detects civic issues from uploaded images, identifies the responsible department, and generates complaint reports.

## Features

- Upload an image of a civic issue
- AI analyzes the image
- Detects the type of issue
- Predicts severity
- Assigns the responsible government department
- Generates an automatic complaint

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- Google Gemini API
- Pillow
